🔧 构建 APK 步骤

  1. 下载安装 Android Studio
  2. 打开项目文件夹 gold-price-app
  3. 等待 Gradle 同步完成
  4. 点击 Build → Build APK(s)
  5. APK 位于 app/build/outputs/apk/debug/
