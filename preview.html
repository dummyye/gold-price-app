📦 构建说明

  • 技术栈: Kotlin + Jetpack Compose
  • 最低版本: Android 7.0 (API 24)
  • 目标版本: Android 14 (API 34)
  • 适配机型: 华为、小米、OPPO、vivo、三星等

🔧 构建 APK 步骤

  1. 安装 Android Studio
  2. 打开项目文件夹 gold-price-app
  3. 等待 Gradle 同步完成
  4. 点击 Build → Build Bundle(s) / APK(s) → Build APK(s)
  5. APK 文件位于 app/build/outputs/apk/debug/

💡 提示: 项目代码已准备就绪，使用 Android Studio 打开即可一键构建 APK
